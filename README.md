# 🛒 Análisis de Ventas - Alura Store

## 📌 Propósito
Analizar datos de ventas y reseñas de tiendas de Alura Store para identificar tendencias, evaluar el rendimiento de cada tienda y recomendar decisiones basadas en datos, como cuál tienda cerrar.

## 🧰 Herramientas utilizadas
- Python 3.x
- Google Colab
- Pandas
- Matplotlib
- Seaborn
- Git & GitHub
